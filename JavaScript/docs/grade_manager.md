# 成績管理ミニアプリ（コンソール）メモ

このドキュメントは、Week2 のお題「成績管理ミニアプリ（コンソール）」の学習ログです。

- 対象コード: `JavaScript/src/grade_manager.js`
- 目的: 関数 / 配列 / ループ / 集計（平均・最大・最小）/ 抽出（平均以上）に慣れる

---

## 概念（何を解決するか）

「複数人の点数データ」から、よくある集計を出す練習です。

- 点数一覧（配列）を扱う
- ループで合計・最大・最小を求める
- 条件に合う人だけを抽出する
- 結果をコンソールへ見やすく出力する

---

## 最小実装（Hello World レベルで動かす）

この課題の最小は次の流れです。

1. 点数配列 `score` を用意する（今回は 10 人分）
2. 平均点を求めて表示する
3. 最高点・最低点を求めて表示する（発展）
4. 平均点以上の学生を抽出して表示する（発展）

今の `grade_manager.js` は、上記の流れを関数に分けて実装しています。

---

## 実務での型（よく使うパターン）

### 1) 「データ生成」「計算」「表示」を関数で分ける

`grade_manager.js` は、処理を以下のように分割しています。

- `RandomNumber(score)`：点数を 1〜100 で埋める（データ生成）
- `Average(score)`：平均を返す（計算）
- `Max(score)` / `Min(score)`：最高/最低を返す（計算）
- `AboveAverage(score, average)`：平均以上の人（index）を返す（抽出）
- `console.log(...)`：出力（表示）

この分け方にしておくと、後で
- 点数を「ランダム」ではなく「入力」から作る
- 出力を「画面」や「ファイル」に変える
といった変更がしやすくなります。

### 2) ランダムな 1〜100 の整数を作る式

```js
Math.floor(Math.random() * 100) + 1
```

- `Math.random()` は 0〜1未満の小数
- `* 100` で 0〜100未満
- `Math.floor` で 0〜99 の整数
- `+ 1` で 1〜100

### 3) 「平均以上の学生番号」を見やすく表示する

`AboveAverage(...)` は index（0始まり）を返します。

- 学生番号として表示するには `+1` が必要
- 配列を文字列にするには `join` が便利

```js
aboveAverage
  .map((i) => i + 1)  // 0始まりindex → 1始まり番号
  .join(", ");       // "1, 3, 7" のように表示用文字列へ
```

## 落とし穴（よくあるエラーと回避策）

- **配列の作り方**
  - JavaScript では `let score[10];` は使えません。
  - 10個ぶんの箱を用意するなら `new Array(10)` や `Array(10).fill(0)` を使います。

- **`new Array(10)` は最初「空（empty）」**
  - `score[i] = ...` のように代入して埋める使い方はOKです。
  - ただし `map` などの配列メソッドは、empty 要素があると期待通り動かないことがあります。

- **平均点以上が0人のとき**
  - `aboveAverage` が `[]` になると、`join(", ")` は空文字になります。
  - 表示を「該当なし」にしたいなら、`aboveAverage.length` を見て分岐します。

- **関数名の慣習**
  - JavaScript では関数名は `randomNumber` / `average` のような **camelCase** が一般的です。
  - ただし学習段階では「意味が分かる名前」でOKです。
