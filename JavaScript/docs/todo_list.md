# TODOリスト（コンソール）メモ

このドキュメントは、Week2 のお題「TODOリスト（コンソール）」の学習ログです。

- 対象コード: `JavaScript/src/todo_list.js`
- 目的: `readline` / 配列 / 分岐（`switch`）/ 入力バリデーション / スコープ設計に慣れる

---

## 概念（何を解決するか）

コンソールで「コマンドを入力して、TODOを追加/一覧/削除できる」小さなアプリを作ります。

この課題の本質は **配列操作** だけでなく、Node.js のコンソール入力が **非同期（入力は後から届く）** だという点を踏まえて、
入力待ちが重ならないようにプログラムを組み立てることです。

---

## 最小実装（Hello World レベルで動かす）

最小の到達点は次の通りです。

1. メニューを表示する
2. `command>` で `1/2/3/4` の入力を受け取れる
3. `1`：タイトルを入力して配列に追加できる
4. `2`：配列の内容を番号つきで表示できる
5. `3`：番号を指定して削除できる
6. `4`：終了できる

---

## 実務での型（よく使うパターン）

### 1) `readline` は「1回だけ作って共有」する

`readline.createInterface(...)` は **アプリ全体で1回だけ**作ります。

- 良い：`rl` を1つだけ作り、すべての入力に使い回す
- 悪い：関数ごとに `createInterface` して入力待ちを増やす（競合しやすい）

### 2) 入力待ちの「同時発生」を避ける（非同期の基本）

`rl.question()` は「その場で値が返る」のではなく、
**入力が来た後にコールバックが実行**されます。

そのため、次のような構造にすると壊れやすいです。

- `command>` を待つ `rl.question` を出した直後に
- `Enter todo title:` を待つ `rl.question` も出す

この状態だと、入力プロンプトが重なって混乱します。

#### 解決の型：操作が完了したら「次の command>」へ戻す

今の `todo_list.js` は、以下の考え方で組んでいます。

- `promptCommand()`：コマンドを1回だけ聞く
- `addTodo(done)` / `removeTodo(done)`：追加質問が必要な操作は、終わったら `done()` を呼ぶ
- `done()` の実体は `promptCommand`（＝次のコマンドへ戻る）

こうすると **入力待ちが常に1個**になり、流れが安定します。

### 3) 表示番号（1始まり）と配列index（0始まり）を揃える

ユーザーには通常 1, 2, 3... と見せたい一方で、配列は 0, 1, 2... です。

- 表示：`i + 1`
- 入力：`Number(input) - 1`

削除処理は「変換後の index」でチェックします。

---

## 落とし穴（よくあるエラーと回避策）

- **入力は全部「文字列」**
	- `rl.question(..., (answer) => ...)` の `answer` は常に文字列です。
	- 数として使う場合は `Number(answer)` で変換し、`NaN` を弾きます。

- **`rl.close()` を早く呼びすぎる**
	- 追加操作の最後に `rl.close()` すると、1回追加しただけでアプリが終わります。
	- `rl.close()` は「Exit（4）」のときだけ呼ぶ、という設計が分かりやすいです。

- **`rl.question()` の多重発行（入力待ちの重なり）**
	- `command>` を待っているのに、別の `question` を出すと入力が競合します。
	- 対策：操作の完了をトリガーにして次へ進む（`done()` パターン）

- **削除番号のバリデーション不足**
	- 空入力、数字以外、範囲外（0 や大きすぎる値）を弾けるようにします。

## 説明できる状態（チェックリスト）

- `readline` が「コンソール入力を受ける仕組み」だと説明できる
- `rl.question` は非同期で、入力後にコールバックが動くと説明できる
- `readline` を1回だけ作って共有する理由を説明できる
- 表示番号（1始まり）と配列index（0始まり）の変換を説明できる
- `Number(...)` と `Number.isInteger(...)` の使いどころを説明できる

## 動作確認

PowerShell で実行：

```powershell
node .\JavaScript\src\todo_list.js
```

確認する操作：

1. `1` → 文字を入れて追加される
2. `2` → 一覧が表示される（番号が 1 から始まる）
3. `3` → 番号を入れて削除される（範囲外は弾かれる）
4. `4` → 終了して `Bye!` が出る
