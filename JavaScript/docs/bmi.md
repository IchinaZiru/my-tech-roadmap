# BMI 計算機（コンソール）メモ

このドキュメントは、Week1 のお題「BMI 計算機（コンソール）」の学習ログです。

- 対象コード: `JavaScript/src/bmi.js`
- 目的: 変数 / 演算 / `if` に慣れる

---

## 概念（何を解決するか）
BMI（Body Mass Index）は、身長と体重から体格の目安を計算する指標。

- 計算式: **BMI = 体重(kg) ÷ 身長(m)²**
- 単位が重要: 身長は **m**、体重は **kg**

---

## 最小実装（Hello World レベルで動かす）
最低限やることは次の3つ。

1. `height`（m）と `weight`（kg）を変数に入れる
2. `bmi = weight / (height * height)` を計算して `console.log` で表示
3. `if / else if / else` でカテゴリを出す

カテゴリ例（学習用のシンプル版）
- `bmi < 18.5`: 痩せ気味
- `bmi < 25`: 普通
- それ以外: 太り気味

---

## 実務での型（よく使うパターン）
学習の次の段階として、読みやすさ・安全性を上げる改善。

### 1) `const` を優先する
再代入しない値は `let` ではなく `const` を使う。

- `height`, `weight`, `bmi` は基本的に `const` でOK

補足（簡潔）
- **再代入** = 変数名に「別の値を入れ直す」こと（例：`x = 2`）。`const` は再代入NG、`let` はOK。
- `const` の配列/オブジェクトは **変数の再代入はNG** だが、**中身の変更はOK**（例：`arr.push(...)`、`obj.a = ...`）。

### 2) 表示を丸めて見やすくする
BMIは小数が長くなりがちなので、1桁などに丸める。

- 例: `Math.round(bmi * 10) / 10`

### 3) 判定カテゴリをもう1段階増やす（任意）
「太り気味」が広すぎる場合は、もう少し分ける。

例（よく見かける区分）
- `bmi < 18.5`: 痩せ
- `18.5 <= bmi < 25`: 普通
- `25 <= bmi < 30`: 太り気味
- `30 <= bmi`: 肥満

※団体や国で区分が違うことがあります。学習では1つに固定してOK。

### 4) 出力はテンプレート文字列にする
`"BMI:" + bmi` でも動くが、テンプレート文字列の方が読みやすい。

- 例: ``console.log(`BMI: ${roundedBmi}`)``

補足（簡潔）
- `` `...` ``（バッククォート）は **テンプレートリテラル**。`${...}` で変数を埋め込める（`"文字" + 変数` の代わり）。

---

## 落とし穴（よくあるエラーと回避策）
- **身長の単位ミス**: cm のまま計算しない（170cm は 1.70m に直す）
- **小数が長すぎて見づらい**: 丸める（`Math.round` など）
- **カテゴリ条件の順番**: 小さい条件から順に書く（`bmi < 18.5` → `bmi < 25` …）
- **`let` の使いすぎ**: 変わらない値は `const` にする
- **`const` にした後のエラー**: `const` にした変数へ `=` で代入し直すとエラー（例：`bmi = ...` を後から書き換えようとする）。再代入が必要なら `let`。
- **丸める値の使い分け**: 判定（`if`）は `bmi` のまま行い、表示だけ `roundedBmi` を使うのが安全（丸めた値で判定すると境界付近でズレやすい）。
- **境界条件のミス**: `bmi < 30` と `bmi <= 30` で結果が変わる。まずは「未満（<）」で統一すると混乱しにくい。
- **カテゴリを増やしたときの分岐漏れ**: `else if (bmi < 30)` を追加したら、最後の `else` が何を表すか（例：肥満）を必ず決めて出力する。

- `const` と `let` の使い分けが言える
