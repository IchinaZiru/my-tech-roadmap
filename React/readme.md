# React カウンターアプリ 解説

## 概要

`index.html` を開くだけで動作する、シンプルなカウンターアプリです。
ボタンを押すたびに画面中央の数字が変化します。

---

## 実行方法

ビルド・インストール不要です。`index.html` をブラウザで直接開いてください。
React と Babel は CDN 経由で自動的に読み込まれます。

---

## 画面の構成

```
┌─────────────────────────────┐
│         カウンター            │
│                              │
│            42                │  ← 現在のカウント値（大きく表示）
│                              │
│  [- 減らす] [リセット] [+ 増やす]  │
└─────────────────────────────┘
```

---

## 動作の詳細

### 1. ボタンの役割

| ボタン | 動作 | 色 |
|--------|------|----|
| `+ 増やす` | カウントを 1 増やす | 青 |
| `- 減らす` | カウントを 1 減らす | 赤 |
| `リセット` | カウントを 0 に戻す | グレー |

### 2. カウント表示の色変化

カウントの値に応じて、表示される数字の色が変わります。

- **正の数（1以上）** → 青 `#2563eb`
- **負の数（-1以下）** → 赤 `#dc2626`
- **ゼロ** → 黒 `#374151`

---

## コードの解説

### useState でカウントを管理する

```js
const [count, setCount] = useState(0);
```

`useState(0)` は「初期値 0 の状態変数」を作成します。
- `count` ：現在のカウント値を保持する変数
- `setCount` ：`count` を更新するための関数

`setCount` を呼び出すと、React が画面を自動的に再描画します。
これが React の **リアクティブな UI 更新** の仕組みです。

---

### ボタンのクリックで状態を更新する

```jsx
<button onClick={() => setCount(count + 1)}>+ 増やす</button>
<button onClick={() => setCount(count - 1)}>- 減らす</button>
<button onClick={() => setCount(0)}>リセット</button>
```

`onClick` にアロー関数を渡すことで、ボタンを押したときだけ処理が実行されます。
`setCount` に新しい値を渡すと `count` が更新され、画面が再描画されます。

---

### 三項演算子で色を動的に切り替える

```jsx
color: count > 0 ? "#2563eb" : count < 0 ? "#dc2626" : "#374151"
```

`条件 ? 真のとき : 偽のとき` という三項演算子を使い、
`count` の値に応じてスタイルを動的に変えています。
JSX ではこのように JavaScript の式を `{}` の中で直接書くことができます。

---

### コンポーネントを DOM にマウントする

```js
const root = ReactDOM.createRoot(document.getElementById("root"));
root.render(<Counter />);
```

HTML 内の `<div id="root">` を起点として、React アプリを描画します。
`ReactDOM.createRoot` は React 18 から導入された新しい API です。

---

## 学習のポイント

- **`useState`** ：コンポーネント内に状態（データ）を持たせる基本の Hook
- **イベントハンドラ** ：`onClick` でユーザー操作に反応する
- **条件付きスタイル** ：`{}` 内の JS 式でスタイルを動的に変更する
- **コンポーネント** ：UI を関数として部品化する React の基本設計
