# Lesson 02: Components（コンポーネント）

## このレッスンで学ぶこと

UIを「部品（コンポーネント）」に分割する考え方。
コンポーネントは「JSXを返す関数」。大文字始まりの名前をつける。
同じコンポーネントを複数回使うことで再利用できる。

---

## 何を実装するか

`src/lessons/02-components/ComponentsLesson.jsx` に以下を全て含むコードを書く。

### 実装チェックリスト

- [ ] 小さなコンポーネントを2〜3個作る（例：`Header`、`Card`、`Footer`）
- [ ] 作ったコンポーネントを別のコンポーネントの中で使う（入れ子）
- [ ] 同じコンポーネントを2回以上使って「再利用」を確認する

### 画面イメージ

```
[Header コンポーネント]

[Card コンポーネント]  ← 同じCardが2回表示される
[Card コンポーネント]
```

---

## App.jsx への接続方法

```jsx
import ComponentsLesson from './lessons/02-components/ComponentsLesson'
{ label: '02 Components', Component: ComponentsLesson },
```

## 学習ノート（実装後に自分で埋める）

### 概念
<!-- コンポーネントとは何か、なぜ分割するのか -->
UIの部品。外で定義すればいつでも呼び出し、再利用することができる
コードが軽量で済む
### 最小実装
```tsx
function Header(){・・・}

return(
    <Header />
)
```

### 実務での型
```tsx
function Header(){・・・}
```

### 落とし穴
関数名の始まりは小文字ではなく大文字(headerではなくHeader)

### 説明できる状態
<!-- 口頭で人に説明できるようになったら1〜2文でまとめる -->
コンポーネントは定義した関数を後から呼び出して使用することのできる機能
同じファイル内で定義された関数はそのファイルでしか使用できないが、外部からコンポーネントファイルをimportすればどこからでも部品を再利用することができる
