# Lesson 06: 文字列バリデーション

## このレッスンで学ぶこと

### バリデーション（validation）とは

バリデーションとは「データが正しい形・範囲・形式かを確認すること」です。
「文字列であること」だけでなく、「メールアドレスの形式であること」「3文字以上であること」
なども検証できます。

### 文字列バリデーションの種類

```ts
z.string().min(3)              // 最小文字数: 3文字以上
z.string().max(20)             // 最大文字数: 20文字以下
z.string().length(8)           // ちょうど8文字
z.string().email()             // メールアドレス形式
z.string().url()               // URL形式
z.string().startsWith("https") // "https" で始まる
z.string().endsWith(".jp")     // ".jp" で終わる
z.string().includes("@")       // "@" を含む
z.string().regex(/^[a-z]+$/)   // 正規表現に一致
```

### カスタムエラーメッセージ

第2引数にメッセージを渡すか、オブジェクトで設定できます：

```ts
z.string().min(3, "3文字以上入力してください")
z.string().email({ message: "メールアドレスの形式が正しくありません" })
```

### メソッドチェーン

複数のルールを組み合わせられます：

```ts
z.string().min(3).max(20).email()
```

## ヒント

`safeParse()` を使うとエラーが出てもクラッシュしません
（`safeParse()` の詳細は Lesson 08 で学びます）：

```ts
const result = schema.safeParse(値)
if (result.success) {
  // 成功: result.data に検証済みデータ
} else {
  // 失敗: result.error.issues[0].message にエラーメッセージ
}
```
