# Lesson 01: Hello World

## このレッスンで学ぶこと

### Zod の「スキーマ」とは

Zod の中心にある考え方は **スキーマ（schema）** です。

スキーマとは「このデータはこういう形であるべきだ」という定義のことです。

```ts
// 「文字列であるべき」というスキーマ
const schema = z.string()
```

スキーマに `.parse()` というメソッドを使うと、データを検証できます。

- 定義通りなら → そのデータをそのまま返す
- 定義と違うなら → エラーを投げる

```ts
schema.parse("Hello, Zod!")  // → "Hello, Zod!" を返す
schema.parse(123)            // → エラー！数値は文字列ではない
```

### なぜ Zod を使うのか

TypeScript は「コンパイル時」の型チェックはできますが、「実行時」のデータ検証はできません。
外部から来るデータ（フォームの入力値、APIのレスポンスなど）の型は保証されません。
Zod を使うと、実行時にデータの形を検証できます。

## ヒント

### Zod のインポート方法

```ts
import { z } from 'zod'
```

### スキーマの作り方と使い方

`z.string()` を呼ぶと「文字列スキーマ」ができます。
そのスキーマに `.parse(値)` を呼ぶと検証が走ります。
`try { ... } catch (e) { ... }` でエラーをキャッチできます。
