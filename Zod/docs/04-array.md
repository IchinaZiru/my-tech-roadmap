# Lesson 04: 配列

## このレッスンで学ぶこと

### z.array() とは

`z.array()` は「配列のスキーマ」を定義します。
引数に「配列の要素のスキーマ」を渡します。

```ts
z.array(z.string())  // 文字列の配列
z.array(z.number())  // 数値の配列
```

### 検証の仕組み

配列の全要素が指定したスキーマに合っているかをチェックします：

```ts
const schema = z.array(z.string())

schema.parse(["Alice", "Bob"])   // OK
schema.parse(["Alice", 123])     // エラー: 123 は文字列ではない
schema.parse("Alice")            // エラー: 配列ではない
```

### オブジェクトの配列

`z.object()` と組み合わせてオブジェクトの配列も作れます：

```ts
const usersSchema = z.array(
  z.object({
    id: z.number(),
    name: z.string(),
  })
)
```

### 長さの制限

`.min()` / `.max()` / `.length()` で配列の長さも制限できます：

```ts
z.array(z.string()).min(1)     // 1つ以上
z.array(z.string()).max(10)    // 10個以下
z.array(z.string()).length(3)  // ちょうど3個
```

## テストケース

```json
// 正常
["Alice", "Bob", "Charlie"]

// エラー: 数値が混じっている
["Alice", 123, "Charlie"]

// 空配列（通る）
[]

// オブジェクトの配列
[{"id": 1, "name": "Alice"}, {"id": 2, "name": "Bob"}]
```

---

## ヒント

配列スキーマは `z.array(要素のスキーマ)` の形です。
中身を見て「要素に何のスキーマを使うか」を考えてから書くとスムーズです。
