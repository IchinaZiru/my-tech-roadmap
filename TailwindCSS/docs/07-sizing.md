# Lesson 07: Sizing

## このレッスンで学ぶこと

### サイズの指定方法

Tailwind のサイズ指定は3種類の書き方がある。

1. **固定値**: `w-32`（128px）のようにスペーシングスケールで指定
2. **割合**: `w-1/2`（50%）・`w-full`（100%）のように親要素比で指定
3. **ビューポート**: `w-screen`（画面幅100%）・`h-screen`（画面高さ100%）

### なぜ max-w を使うのか

`w-full` だけだと、画面が大きくなるにつれて要素も横に広がりすぎて読みにくくなる。`max-w-prose` や `max-w-2xl` で上限を設けると、どの画面サイズでも読みやすいレイアウトになる。

## ヒント

### 幅のクラス早見表

```
w-4      → 16px
w-8      → 32px
w-16     → 64px
w-32     → 128px
w-48     → 192px
w-64     → 256px
w-1/2    → 50%
w-1/3    → 33.3%
w-2/3    → 66.7%
w-full   → 100%
w-screen → 100vw（ビューポート幅）
```

### max-w の大きさ

```
max-w-xs   → 320px  （小さいモーダル）
max-w-sm   → 384px  （サイドバー）
max-w-md   → 448px  （フォーム）
max-w-lg   → 512px  （カード）
max-w-xl   → 576px
max-w-2xl  → 672px
max-w-3xl  → 768px
max-w-4xl  → 896px
max-w-5xl  → 1024px
max-w-6xl  → 1152px
max-w-7xl  → 1280px （ページ全体の最大幅によく使う）
```

### ページ全体のレイアウトに使う典型パターン

```tsx
// ページのコンテンツを中央に収める
<div className="max-w-4xl mx-auto px-4">
  コンテンツ
</div>
```
