# Lesson 04: Colors

## このレッスンで学ぶこと

### Tailwind のカラーシステム

カラーは `{色名}-{濃さ}` の形式。

- **色名**: `red` / `orange` / `yellow` / `green` / `blue` / `purple` / `pink` / `gray` / `sky` / `teal` など
- **濃さ**: `50`（最も薄い）〜 `950`（最も濃い）

```
bg-blue-50   → ほぼ白に近い薄い青（背景に使いやすい）
bg-blue-500  → 標準的な青（ボタンなどに使いやすい）
bg-blue-900  → 濃い青（ダークテーマに使いやすい）
```

### なぜ番号で管理するのか

デザインに一貫性が生まれる。「青系は blue-500 をメインカラーにして、薄い背景は blue-50 を使う」のようなルールを作れる。`#1a73e8` のような16進数より覚えやすく、チームで共有しやすい。

## ヒント

### よく使う色の名前

```
gray    → 無彩色。テキスト・ボーダー・背景に幅広く使う
red     → エラー・削除ボタン・警告
yellow  → 注意・ハイライト
green   → 成功・完了・正常
blue    → 情報・リンク・プライマリカラーによく使う
sky     → 青より明るい。ボタンや見出しに
purple  → プレミアム感・アクセント
pink    → 女性向けデザイン・アクセント
```

### 透明度の書き方（v4 の記法）

```tsx
// スラッシュで透明度を指定する
<div className="bg-blue-500/50">50% の透明度</div>
<div className="bg-blue-500/30">30% の透明度</div>
<p className="text-black/60">60% の透明度のテキスト</p>
```

### カラースケールを並べるアイデア

```tsx
// .map() で並べてみると確認しやすい
const shades = [50, 100, 200, 300, 400, 500, 600, 700, 800, 900]
shades.map(shade => (
  <div key={shade} className={`bg-blue-${shade} p-4`}>{shade}</div>
))
```

> 注意: Tailwind はビルド時にクラスをスキャンするため、テンプレートリテラルで動的にクラスを生成すると効かないことがある。完全なクラス名 `bg-blue-100` を書くのがベスト。
