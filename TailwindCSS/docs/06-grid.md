# Lesson 06: Grid

## このレッスンで学ぶこと

### Grid とは

「格子状（グリッド）」にレイアウトする仕組み。カード一覧・ギャラリー・ダッシュボードなど、**2次元のレイアウト**（横にも縦にも整列させたい）に強い。

### Flexbox との使い分け

| | Flexbox | Grid |
|--|---------|------|
| 得意 | 1次元（横一列 or 縦一列） | 2次元（縦横のグリッド） |
| 典型例 | ナビバー・ボタン群・カードの中身 | カード一覧・ギャラリー・レイアウト全体 |

### なぜ Grid を使うのか

同じ幅のカードを3列並べたいとき、Flexbox だと各カードの幅を `w-1/3` などで指定する必要がある。Grid なら `grid-cols-3` の1クラスだけで済む。

## ヒント

### 基本の grid コンテナ

```tsx
// 3列グリッド、16px のギャップ
<div className="grid grid-cols-3 gap-4">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>  {/* 自動的に次の行に折り返す */}
</div>
```

### col-span でセルをまたがせる

```tsx
<div className="grid grid-cols-3 gap-4">
  <div className="col-span-2">2列分の幅</div>
  <div>1列分</div>
  <div>1列分</div>
  <div className="col-span-full">全列幅（col-span-3 でも同じ）</div>
</div>
```

### gap-x と gap-y で縦横を別々に指定

```tsx
// 横のギャップを広く、縦のギャップを狭く
<div className="grid grid-cols-3 gap-x-8 gap-y-2">
  ...
</div>
```
