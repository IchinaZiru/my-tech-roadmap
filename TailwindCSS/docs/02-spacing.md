# Lesson 02: Spacing

## このレッスンで学ぶこと

### スペーシングとは

要素と要素の間の「距離」を作るクラス群。大きく2種類ある。

- **padding**（パディング）: 要素の**内側**の余白。背景色の中に含まれる。
- **margin**（マージン）: 要素の**外側**の余白。隣の要素との距離。

### 4px ベースのスケール

Tailwind のスペーシングは `n × 4px` で計算できる。

```
p-0  → 0px
p-1  → 4px
p-2  → 8px
p-3  → 12px
p-4  → 16px
p-6  → 24px
p-8  → 32px
p-12 → 48px
p-16 → 64px
```

`p-4` = 16px = 典型的なカードのパディング。覚えておくと便利。

### なぜそう書くのか

`p-4` と書けば「16px のパディング」とわかる。`padding: 16px` と書く必要がない。チーム全員が同じスケールを使えば、数値がバラバラにならない。

## ヒント

### 方向の指定方法

```
p-4   → 全方向に 16px
px-4  → 左右に 16px（x軸）
py-4  → 上下に 16px（y軸）
pt-4  → 上だけ 16px（top）
pr-4  → 右だけ 16px（right）
pb-4  → 下だけ 16px（bottom）
pl-4  → 左だけ 16px（left）
```

margin も同じパターン: `m-` / `mx-` / `my-` / `mt-` / `mr-` / `mb-` / `ml-`

### padding と margin の違いを確認する方法

背景色をつけると違いがわかりやすい。

```tsx
// padding: 背景色の内側に余白ができる
<div className="bg-blue-100 p-8">中身</div>

// margin: 背景色の外側に余白ができる
<div className="bg-blue-100 m-8">中身</div>
```

### mx-auto の使い方

`mx-auto` は「左右のmarginを自動で均等にする」 = 水平中央揃え。
ただし `w-{n}` や `max-w-{n}` で幅を指定しないと効かない。
