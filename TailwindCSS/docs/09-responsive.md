# Lesson 09: Responsive

## このレッスンで学ぶこと

### レスポンシブデザインとは

画面幅（スマホ・タブレット・PC）に応じてレイアウトを変える仕組み。

### モバイルファーストの考え方

Tailwind はデフォルトで**モバイルファースト**。

- プレフィックスなし → **全サイズに適用**（= モバイルのデフォルト）
- `sm:` → **640px 以上**のとき上書き
- `md:` → **768px 以上**のとき上書き
- `lg:` → **1024px 以上**のとき上書き
- `xl:` → **1280px 以上**のとき上書き

```tsx
// 「モバイルは1列、タブレットは2列、PCは3列」
<div className="grid-cols-1 sm:grid-cols-2 lg:grid-cols-3">
```

### なぜモバイルファーストか

スマホユーザーが多い現代では、まずモバイルのレイアウトを設計して、画面が大きくなるにつれて追加するのが自然な流れ。

## ヒント

### ブレークポイントの一覧

```
sm   → 640px   （大きめのスマホ・小さいタブレット）
md   → 768px   （タブレット）
lg   → 1024px  （小さいPC・大きいタブレット）
xl   → 1280px  （標準的なPC）
2xl  → 1536px  （大きいPC）
```

### よく使うレスポンシブパターン

```tsx
// テキストサイズ: モバイルで小さく、PCで大きく
<h1 className="text-2xl md:text-4xl lg:text-5xl">見出し</h1>

// グリッド: モバイルで1列、PCで3列
<div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4">

// 要素の表示/非表示: モバイルでは非表示
<nav className="hidden md:flex">
  PC用ナビ
</nav>
<button className="md:hidden">
  モバイル用メニューボタン
</button>
```

### 確認方法

Chrome DevTools の「デバイスツールバー（📱アイコン）」でレスポンシブを確認できる。または、ブラウザウィンドウの幅を手動で変えても確認できる。
